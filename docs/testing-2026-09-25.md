# Echo 本地测试版验收

适用于 **Echo v0.4.0**：[发布与下载](https://github.com/michaelmjhhhh/Echos/releases/tag/v0.4.0)。本机开发签名构建位于 `build/testing/0.4.0/Echo.app`；GitHub 分发包的签名状态以发布说明为准。以下检查约 10–15 分钟，不含首次模型下载和加载。目标是检查真实英语口述、松键后的等待时间及操作一致性；这份清单本身不代表所有设备验收已经通过。

## 启动与基线

1. 先从旧 Echo 的菜单选择 **Quit Echo**，再打开新版本，避免两个版本同时运行。分发包按 Release 的安装说明处理。如果 Home 显示 **Needs permissions**，在系统设置中允许新应用使用麦克风和辅助功能，再返回等待就绪。
2. 此版本沿用 Echo 的应用标识，与旧版共享设置、模型、词典和历史。签名与现有 `/Applications/Echo.app` 不同，系统可能要求重新授权；原有辅助功能授权未生效时，在 **System Settings → Privacy & Security → Accessibility** 移除旧条目并添加上述路径的应用，再重新打开。若另有麦克风提示，也在对应 **Microphone** 页面允许。使用临时测试内容，不要使用 **Clear History / Delete All / Delete statistics**。
3. 打开 **Settings**：依次测试 **System Default** 和 **MacBook Air 麦克风**，每种连续按住 Fn 说话三次。波形应保持至松键，不再出现 `CADefaultDeviceAggregate-...` 菜单项。旧临时设备选择会自动回到 System Default。记录当前模型，保持模型不变。默认仍是 **Distil Large v3**。**Spoken language** 设为 **English**；英语模型显示 **English only for this model**。先保留 **Dictionary hints = 200 tokens**、**Retry difficult speech = Up to 5 times**，不同时调整多个参数。
4. 等待 Home 显示 **Ready when you are**。首次模型加载和预热单独记录，不计入口述延迟。打开 TextEdit 新建空白文稿，切到纯文本并放好光标。你当前的 **Dictation key 是 Fn**，按住说话、松开结束；以应用实际显示为准。若 Fn 同时触发系统听写或表情面板，可按设置中的说明把系统键盘的 Fn 操作设为 **Do Nothing**，或在 Echo 手动改用 **Right Option**。

## 核心检查

| 项目 | 操作 | 预期与记录 |
| --- | --- | --- |
| 普通英语与速度，2 分钟 | 口述下方短句一次作预热，再以相同语速重复 3 次。说完最后一个词即松键。 | 每次只插入一次，首尾词完整；记录错词、漏词和多词。每次从松键计时到文字出现，记录 3 个时间，标点差异单独记。出现 Copy 提示则记录原因和提示出现时间，不把它当作自动粘贴成功。 |
| 短音频，1 分钟 | 分别说 **Yes**、**No**，每个重复 3 次；每次完整按住约 0.5–1 秒。 | 不应因不足 1 秒而稳定返回空白。记录每次是否出现词；大小写和句号不算错误。不要用极短误触作为样本。 |
| 长段尾部，2 分钟 | 自然口述至少 35 秒；最后清楚说 **The final word is pineapple**，说完立即松键。可用下方长段。 | 对照全文，重点检查最后一句和 **pineapple** 是否保留、是否重复。记录总口述时长和松键等待时间。 |
| 取消与下一次口述，1 分钟 | 口述一段，在悬浮条或 Echo 菜单点 **Cancel Dictation**；再试一次，在 **Transcribing…** 阶段取消。恢复 Ready 后口述 **This is the next recording**。 | 取消中的状态可短暂持续；被取消内容之后也不应突然插入或新增到 History。下一次录音正常，且只包含新内容。 |
| 切换目标，1 分钟 | 从 TextEdit 开始口述，保持按键，鼠标切换到另一个应用后再松键。 | 新应用不应收到自动粘贴；Echo 提示目标变化并保留 **Copy**。点击 Copy，再手动粘贴到测试文稿，内容应可取回。 |
| 剪贴板，2 分钟 | 关闭 **Copy transcript to clipboard**。先复制 `QA original clipboard`，回 TextEdit 口述并等 1 秒，再手动粘贴检查。随后再口述一次，文字出现后立即复制文稿内预先准备的 `QA newer clipboard`，等 1 秒再粘贴。最后开启该设置并重复一次口述。 | 关闭时，第一次恢复原剪贴板；第二次保留用户新复制的内容，不被延迟恢复覆盖。开启时，剪贴板保留最新转写。第二次操作若没有赶在恢复前完成，记为“未覆盖该时序”，不算已验证。 |
| 左右按键，1 分钟 | 暂用 **Right Option**：同时按住左、右 Option 口述，只松开右 Option，稍后再松左 Option。 | 松开右键即结束录音，不应等待左键松开，也不应触发第二次录音。测试后恢复原快捷键。 |
| 文本规则，2 分钟 | 按下一节使用编辑器预览和临时 snippet。 | 预览验证确定的文本处理；真实口述再验证识别到展开的完整链路。两种失败分别记录。 |
| 退出与保存，1 分钟 | 保留一条临时规则和一条测试历史，正常 **Quit Echo**，重新打开同一路径。 | 两者仍存在，设置保留，没有无故显示空白或保存错误。随后只删除此次临时规则及测试历史，再重开确认它们不复活。 |

短句：

> Please send the updated project notes to the design team before Friday. The first meeting starts at nine thirty, and the final review is scheduled for next Tuesday.

长段示例；若读完不足 35 秒，补充自己的计划，最后仍使用指定结尾：

> Today I am testing a local dictation application with the same speech model that I used before. I want to check whether it captures the beginning of each sentence and keeps the last few words when I release the key. Tomorrow I will review the project notes, compare the first draft with the revised version, and send a short summary to the design team. I will keep the microphone and speaking distance the same throughout this recording. The final word is pineapple.

## 临时文本规则

只使用下面的临时项；名称若已存在，换一个唯一名称。

1. 在 **Dictionary** 新增：**Word = QA_CPP**，开启 **Correct a misspelling**，**Echo mishears it as = C++**。保持 **Also match in links, email and code** 关闭。在预览输入 `I use C++ and C++@example.com.`，应得到 `I use QA_CPP and C++@example.com.`。这一步不依赖语音模型能否识别出 `C++`。
2. 在 **Snippets** 新增 **When you say = test signature**，将 **Echo types** 填成下面三行，开启 **Only when spoken on its own**。预览 `test signature` 应完整展开；预览 `Please discuss test signature tomorrow` 应保留原句。保存后，在 TextEdit 单独口述 “test signature”，检查换行、大小写、邮件地址、美元符号和反斜杠原样保留，`C++` 不应变成 `QA_CPP`。

   ```text
   C++
   QA.Team@example.com
   $1\done
   ```

3. 关闭 Settings 中 **Expand spoken snippets**，再次口述 “test signature”，应输出识别到的触发短语，不展开。完成后恢复原开关。若想额外检查不递归展开，可新增临时 snippet：`C++` → `SHOULD_NOT_APPEAR`；第一条 snippet 的首行仍须保持 `C++`。

## 可选扩展

- 内置麦克风完成后，再用蓝牙耳机重跑普通句、短句和长段尾部；记录 Home 的实际麦克风名称。设备切换或断开时，应有反馈；产生待复核内容时使用 Copy，不要求强行自动粘贴。
- 在自己常用的浏览器输入框或编辑器重复普通句、切换目标和剪贴板检查。只使用空白测试文档，不向真实邮件、聊天或表单提交内容。
- 需要比较优化前后时，逐次退出一个版本再打开另一个，保持模型、麦克风、词典、设置、文本和语速一致。分别记录首次启动与稳定使用；三次人工计时只是初筛，不作为准确率或速度提升百分比。
